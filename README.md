During this activity, I learned how to solve algorithmic problems using arrays, vectors, strings, and hash maps. I also learned the importance of selecting efficient algorithms based on time and space complexity. The Diagonal Difference problem helped me understand matrix traversal and diagonal calculations. Dynamic Array introduced dynamic sequences and bitwise XOR operations for efficient query processing. Time Conversion improved my understanding of string manipulation and conditional logic. Compare the Triplets strengthened my understanding of element-wise comparison and score tracking. Sparse Arrays demonstrated how frequency mapping can improve string searching efficiency. I also learned how to organize programming solutions professionally using GitHub and document their complexity. Overall, this activity improved my problem-solving ability and helped me understand how algorithmic efficiency contributes to developing effective software solutions.
